# 生命周期源码带读提纲

每个项目围绕同一组问题阅读；具体实现决定讲解内容，不预设必须使用的库或模式。

## 阅读顺序

1. 固定源码版本，找到实际服务入口。
2. 追踪配置、资源和业务对象的初始化顺序。
3. 找到开始监听和允许接收工作的时刻。
4. 检查启动中途失败、运行组件失败的处理。
5. 追踪停止通知、新工作控制、已有工作收尾和资源关闭。
6. 记录超时策略，以及异常终止后的恢复线索。

解释关键代码时说明文件、函数、调用关系和失败路径。只有实现确实依赖某个工具时，才解释理解该段代码所必需的语义；独立专题不作为带读前置要求。

## 比较的问题

| 问题 | 需要取得的证据 |
| --- | --- |
| 何时可用？ | 初始化条件、监听与就绪判断 |
| 启动失败怎么办？ | 部分成功的资源由谁清理 |
| 运行失败怎么办？ | 错误由谁接收，是否触发整体退出 |
| 如何停止新工作？ | 网络入口、已有会话、任务分发的控制 |
| 已有工作如何结束？ | 完成、取消、归还与等待的实际接线 |
| 资源何时关闭？ | 使用者结束与资源释放的顺序 |
| 等待多久？ | 各阶段期限与最外层预算 |
| 突然终止怎么办？ | 可恢复状态、重复执行与业务承诺 |

## 实践衔接

围绕服务器行为设计实验：部分启动失败、在途请求、后台工作收尾、超时和异常终止。使用哪个库由实验要验证的问题决定。
