# Go 语言原理与实践

独立研究 Go 本身的机制、设计与库的使用。收录边界：拿掉具体服务器项目后，内容仍然完整，具有独立学习价值。

原理文档一篇讨论一个问题，直接放在 `go-language/` 下。暂不预设分类或研究清单；等文档积累到查找、阅读需要整理时，再按实际内容做阶段性整理。参考资料随对应文档保存。

生产场景的异常现象与排查案例放在 `cases/`，围绕一个共同问题组织，并从对应原理文档链接进入。例如：[并发与 CPU：五个服务变慢的真实案例](cases/concurrency-performance.html)，与 [GMP 调度模型](gmp-scheduler.html) 关联。

本主题与 [Go 服务器工程手册](../go-server-engineering/README.md) 平级。具体项目中的应用、实现比较与工程决策留在服务器工程主题，需要时通过相对链接关联。
