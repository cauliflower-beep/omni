# 阅读与交互约定

## 阅读路径

模块问题 → 最小示例 → 样本实现 → 横向比较 → 自己的选择 → 实验。支持按模块和按样本进入同一份内容。

## 页面规划

首页 / 学习路线 / 样本列表与详情 / 模块列表与详情 / 横向矩阵 / 专题 / 实验 / 工程实践。内容 id 与实际路径先保持稳定，正式路由在实现时确定。

## 阅读体验

正文宽度、字号与行距适合中文长文；提供清晰的层级、页内目录、代码高亮与复制。长代码可折叠，原始源码链接保留。窄屏下布局可用，表格可横向滚动。深浅主题保证对比度，不仅用颜色表达状态。

## 来源与状态

清楚区分事实、推断和假设；展示样本分析版本、实际核验日期与待验证状态。没有分析的数据不填充假内容，也不显示成已完成。

## 动效边界

演示服务于解释，支持播放、暂停、重置或逐步查看，支持键盘和减少动画偏好。动画采用的简化模型和边界明确标注。模拟不是 Go 执行结果，不作为吞吐或延迟数据。复杂演示的逻辑与文章分离，并链接 labs 中的验证实验。

## 验收占位

正式开发后检查：主要导航可达、链接可用、搜索与过滤正确、代码可复制、键盘可操作、窄屏可读、减少动画有效、无虚构内容和结果。当前仅为设计约定，没有完成网站验收。
