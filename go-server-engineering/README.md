# Go 服务器工程手册

面向已有 Go 服务开发经验的持续复盘项目：从真实开源产品取得源码证据，以服务器模块为主线比较实现，通过可复现实验与完整业务验证，逐步形成自己的工程方法和脚手架。

## 从这里开始

- [学习路线](roadmap.md)：按问题推进，记录下一步与完成条件。
- [样本档案](samples/README.md)：认识产品、固定版本、定位代码入口。
- [模块地图](modules/README.md)：按职责拆解服务器能力。
- [横向分析入口](modules/matrix.md)：查看样本与模块的对应关系和进度规则。
- [Go 专题](topics/README.md)：补充并发、错误、资源管理与性能知识。
- [验证实验](labs/README.md)：区分预期结果与实际观察。
- [工程实践](practice/README.md)：方法、决策、完整应用与脚手架。
- [网站展示层](website/README.md)：HTML 阅读界面、对比组件与概念演示的预留位置。
- [记录模板](templates/README.md)：统一证据、分析和实验的写法。
- [维护约定](CONTRIBUTING.md)：如何添加样本、模块和分析。

## 内容与展示的边界

知识内容保存在 samples/、modules/、topics/、labs/ 和 practice/；结构化索引保存为 JSON。网站以后读取这些来源并呈现 HTML，不另存一套文章。当前只建立目录、说明和模板，没有安装前端框架，也没有可运行的网站或 Go 应用。

阅读顺序：模块问题 → 样本实现 → 横向比较 → 实验验证 → 自己的实践准则。
